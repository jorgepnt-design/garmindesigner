Garmin Designer

Design-Datei (JSON) hochladen und als Zifferblatt (.prg) für die Garmin Venu X1 herunterladen.

1. Zugang zu GitHub

So bekommst du den Schlüssel (einmalig)
  1. github.com/settings/personal-access-tokens/new öffnen.
  2. Token name: z. B. Garmin Designer. Expiration: z. B. 1 Jahr.
  3. Repository access: „Only select repositories“ → garmindesigner.
  4. Permissions → Repository permissions: Contents auf „Read and write“, Actions auf „Read-only“.
  5. Unten auf Generate token klicken, den Schlüssel kopieren und hier einfügen.

Der Schlüssel bleibt nur in diesem Browser gespeichert und geht nur an GitHub.

2. Design hochladen

JSON-Datei hierher ziehen oder auswählen

    3. Fertige Zifferblätter

    Die .prg herunterladen, Uhr per USB anschließen und die Datei in den Ordner GARMIN/APPS kopieren. Danach auf der Uhr das Zifferblatt lange drücken und auswählen.
